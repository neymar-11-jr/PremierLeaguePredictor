# 英超比赛结果预测系统

##  1 项目简介
本项目基于随机森林机器学习算法，利用2023-2024、2024-2025、2025-2026三个赛季的英格兰足球超级联赛的历史比赛数据，构建了一个可交互的足球比赛结果预测系统。系统通过实时计算球队近期状态、交锋历史、进球效率及主客场优势四个核心特征，对任意指定对阵输出胜、平、负的概率预测。项目实现了从数据采集、特征工程、模型训练到 Web 应用部署的完整流程，旨在为足球数据分析爱好者提供一个可用的预测工具，并验证基于历史赛果的统计模型在足球预测中的有效性。

##  2 功能说明
1. 实时数据接入：通过 Football-Data.org 官方 API 自动获取最新英超比赛数据，确保预测依据的时效性。
2. 动态特征计算：用户选择主客队后，系统实时从历史数据中计算以下四个特征： 
             `home_form`：主队近 5 场比赛的胜率（冷启动时自动采用联赛平均主胜率填充）。 
             `h2h_advantage`：主队在过去 3 次与客队交锋中的胜率。  -
             `attack_vs_defense`：主队近 5 场平均进球数与客队近 5 场平均失球数的差值，衡量进球得分能力对比。  
             `home_advantage`：主队本赛季的主场胜率，体现场地加成。
3. 概率预测 ：基于训练好的随机森林模型，输出主队获胜、平局、客队获胜的概率，并以可视化方式呈现。   

##  3 设计思路

### 3.1 总体架构
项目遵循“数据采集 → 特征工程 → 模型训练 → 应用部署”的标准机器学习流程，采用模块化设计，各组件职责清晰、便于维护。
### 3.2 数据采集
通过 football-data.org 官方 API 爬取 2023-2024、2024-2025、2025-2026三个赛季的英超比赛记录（共 1070 场），导出CSV文件作为基线数据，在 data_fetcher.py 模块中封装 API 请求逻辑，每次启动应用或触发模型更新时，自动拉取最新完赛场次，并与本地数据合并。
### 3.3 特征工程
特征工程是决定模型性能上限的关键环节。本项目从原始比分数据中抽象出四个具备明确足球语义的特征：
 1. 主队近期状态 (home_form) ：主队在近 5 场（含主客）比赛中的胜率，反映球队近期竞技状态和势头。冷启动默认值为联赛整体主胜率 (≈45.6%)
 2. 交锋历史优势 (h2h_advantage)： 主队在过去 3 次与客队交锋中的胜率，捕捉心理优势和战术克制关系。冷启动默认值为0.5（中性假设）
 3. 得分效率对比 (attack_vs_defense)： 主队近 5 场场均进球 – 客队近 5 场场均失球，反映两队得分差距。冷启动默认值为联赛场均进球/失球均值
 4. 主场优势 (home_advantage) ：主队在本赛季所有主场比赛中的胜率，考虑主场优势对于球队赢得比赛的作用
### 3.4 数据处理
1. 采集数据预处理
   时间排序：所有数据按 date 字段升序排列，确保特征计算遵循“时间因果律”（只用过去预测未来）。
   去重机制：合并实时数据时，基于 (date, home_team, away_team) 组合键去重，保留最新记录。
   缺失值处理：对于赛季初无历史数据的冷启动场景，使用联赛整体均值（如整体主胜率、场均进球）填充，避免模型输入缺失。
2. 引用特征后数据处理
   滚动时间窗口：所有特征均使用 date < current_date 条件严格过滤，杜绝“未来信息泄露”。
   数据隔离：主场优势特征仅统计主队作为主队时的比赛，攻防特征区分主客队身份计算，保证语义准确性。
   特征迭代：曾尝试引入变量is_early_season以解决跨赛季球队状态变化的问题，但实验显示该特征重要性接近于零且导致准确率下降，故最终未采用。
### 3.5 模型选择与训练
在项目初期，为了快速验证特征有效性，选择逻辑回归作为基线模型，准确率为61.68% 。后考虑到在系统优化的过程中增加了特征，最终选取随机森林为最终模型，准确率提升至64.02% 。采集数据样本的80%作为训练集，20%作为测试集，固定随机种子 random_state=42，确保结果可复现。
训练结果：
基线模型（2 特征 + 逻辑回归）：准确率 61.68%
升级模型（4 特征 + 随机森林）：准确率 64.02%
特征重要性排序：home_advantage (46.5%) > attack_vs_defense (29.2%) > home_form (13.5%) > h2h_advantage (10.8%)

从训练结果中可以看出，主场优势是预测英超比赛结果的最强信号，其次是得分效率对比，而近期状态和交锋历史的贡献相对较小。这一发现符合足球运动中“主场优势”的普遍认知，验证了模型的有效性。
### 3.5 Web 应用设计
考虑python代码的适配性，选取Streamlit作为部署平台
#### 交互流程
  1. 用户通过下拉框选择主队和客队（球队列表从数据集中动态提取）。
  2. 点击“开始预测”后，系统实时调用特征计算模块，生成与训练时完全一致的特征向量。
  3. 加载预训练模型进行概率预测，并输出胜/平/负三类概率。
  4. 用户可展开“查看特征值”面板，了解本次预测的依据。
#### 性能优化
  1. @st.cache_resource 缓存模型加载。
  2. @st.cache_data(ttl=600) 缓存数据加载，10 分钟内不重复请求 API，避免触发频率限制。
### 3.6 局限性与未来改进
1. 数据断层：赛季改变，球队换帅、球员转会等因素会导致比赛数据参考价值下降。当前版本未进行特殊处理，后续可引入赛季内独立窗口或时间衰减权重。
2. 特征维度：受限于数据源，目前系统仅使用比分数据，后期可通过改变信息源，融合预期进球（xG）、球员身价、伤停信息、赔率等更高维特征。
3. 模型学习：目前模型训练基于1070场历史数据，一方面模型短期内不频繁变动，保证稳定性，但另一方面，随时间推移，预测准确率可能会下降。后续可对模型代码进行进一步优化。

##  4 使用指南
1. 打开1.1的网页链接，系统自动加载并显示下拉选择框。
2. 在“主队”下拉框中选择主队名称，在“客队”下拉框中选择客队名称。
3. 点击“开始预测”按钮，系统自动计算特征并调用模型。
4. 页面显示三个概率值（胜/平/负），并可展开查看当前对阵的详细特征值。
